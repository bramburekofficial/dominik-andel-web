# Dominik Anděl Web

Prezentační web pro Dominika Anděla zaměřený na:

* fasády
* zateplování
* zednické práce
* malování

## Funkce

* responzivní design
* galerie realizací
* zvětšení fotografií po kliknutí
* rozklikávací menu
* kontaktní formulář
* PHP validace formuláře
* Po vyplnění formuláře se odešle na email
* Po kliknutí na "Ochrana osobních údajů" se rozklikne další stránka, kde je vše vypsáno a je zde také proklik na hlavní stránku.

## Struktura projektu

```text
dominik-andel-web/
├── index.html
├── style.css
├── kontakt.php
├── README.md
└── images/
```

## Spuštění přes XAMPP

1. Nakopírujte projekt do:

```text
C:\xampp\htdocs\dominik-andel-web
```

2. Spusťte Apache v XAMPP.

3. Otevřete:

```text
http://localhost/dominik-andel-web/
```
